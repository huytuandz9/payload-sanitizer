# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In brief:
- Be respectful and inclusive.
- Assume good intent; disagree constructively.
- No harassment, discrimination, or personal attacks.

## Enforcement

If you experience or witness unacceptable behavior:
- Prefer opening a private report via the repository’s GitHub **Security**/**Report abuse** tools, or
- Email the maintainers at **conduct@example.com**.

The maintainers will review and respond as promptly as possible, and may take any action they deem appropriate.
