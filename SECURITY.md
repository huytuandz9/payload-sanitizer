# Security Policy

## Reporting a vulnerability

- Use GitHub’s private **Security Advisory** workflow for this repository, or
- Email **connect@mohitul-islam.com** with details and a repro if possible.

Please avoid filing public issues for security reports.

## Supported versions

We support the latest released version. If you rely on an older version, please state that in your report so we can coordinate a fix or a backport if feasible.
