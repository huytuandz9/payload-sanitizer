## 📋 What is payload-sanitizer?

payload-sanitizer is a small tool that helps clean up data sent between parts of a web app, like between your browser and the server. It removes empty pieces, trims spaces from words, and allows you to choose which parts to keep or remove. This makes sure the data is tidy and easier for apps to use without errors.

You don’t need to worry about software with lots of extra bits, because payload-sanitizer works with zero dependencies. It works with both frontend (the part you see on the screen) and backend (the server side) programs built with JavaScript or TypeScript.
